飯店住宿助手

個人旅行規劃工具 · Personal travel planning tool

飯店住宿助手是開發者在自己電腦上使用的工具，用來規劃個人的日本旅行。規劃功能包含查詢住宿設施、空房、房型、住宿方案及價格，並連結到原始訂房網站確認詳情。

工具僅供開發者本人使用，不提供他人註冊或對外查詢服務。本頁是公開的工具介紹，住宿查詢程式仍在本機執行。

目前正在申請樂天 API 憑證，尚未啟用樂天的即時住宿查詢。若啟用，查詢結果會標示資料來源，並提供樂天旅遊的原始頁面連結；實際訂房與付款在訂房網站完成。

資料處理

工具沒有自己的訂房或付款系統。API 憑證保存在開發者自己的電腦上；本介紹頁不提供查詢功能，也不刊登個人行程或 API 回應資料。

日本語

飯店住宿助手は、開発者本人が自分のコンピューターで使用する、日本旅行の個人的な計画を支援するツールです。宿泊施設、空室、部屋タイプ、宿泊プランと料金の検索を計画しています。

このページは公開の紹介ページです。ツール自体は個人用のローカルプログラムであり、第三者向けの検索サービスではありません。

楽天APIの利用は申請準備中で、楽天のリアルタイム検索はまだ有効になっていません。利用する場合はデータの提供元を表示し、楽天トラベルの元のページへリンクします。予約と支払いは予約サイト上で行います。

English

This is a personal tool for planning the developer's own trips to Japan. It runs on the developer's computer and is intended to search accommodation, availability, room types, plans, and prices, with links to the original booking pages.

This public page describes the tool; the tool itself is not a public search service. Rakuten API registration is in preparation, and live Rakuten accommodation searches are not enabled. If enabled, results will identify their source and link to the original Rakuten Travel pages. Reservations and payment take place on the booking website.
