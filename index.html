Connector助手

個人自用工具 · Personal-use tool

Connector助手是開發者個人在自己電腦上使用的工具，用來集中管理 Google 等網路服務的授權，讓自己的其他程式能整理 Gmail 郵件與篩選器、管理 Google 日曆與試算表，以及讀取自己的 YouTube 播放清單。每個帳號只授予其實際用途需要的權限。

本工具不對外提供服務、沒有其他使用者，也不經過任何伺服器：授權資料與存取的內容只存在開發者自己的電腦上。

English

Connector助手 is a personal tool that runs only on the developer's own computer. It centralizes authorization for Google and other online services so the developer's own scripts can organize Gmail messages and filters, manage Google Calendar and Sheets, and read the developer's own YouTube playlists. Each account grants only the permissions needed for its actual use.

It is not offered to the public, has no other users, and uses no server. Authorization data and any accessed content stay on the developer's own computer.
